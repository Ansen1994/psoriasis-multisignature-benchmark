# v1.0.0

Initial public release of the analysis code accompanying the PeerJ Research Article:

> Limited cross-cohort added value of published psoriasis transcriptomic signatures: a three-cohort reanalysis

This release contains:

- registration and metadata audit for ten published psoriasis signatures;
- equal-weight positive-direction z-score scoring;
- four biological baseline scores;
- patient-level incremental discrimination and 2,000-replicate bootstrap summaries;
- cross-signature Spearman and participation-ratio effective-dimension analysis;
- GSE154200 treatment and pairing audit;
- independent GSE154200 benchmark;
- generation code for the manuscript figures and supplemental tables.

The code is a transparent comparator benchmark, not an exact reconstruction of the original published models.
