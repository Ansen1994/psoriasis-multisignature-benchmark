# v1.0.2

Archived software release for the PeerJ Research Article:

> Limited cross-cohort added value of published psoriasis transcriptomic signatures: a three-cohort reanalysis

The analysis code is unchanged from v1.0.0. This release records the final archive version in citation metadata and was created after Zenodo repository integration was enabled so that the permanent software DOI could be issued.

This release contains registration and metadata audit for ten published psoriasis signatures; equal-weight positive-direction z-score scoring; four biological baseline scores; patient-level incremental discrimination with 2,000 bootstrap replicates; cross-signature Spearman and participation-ratio effective-dimension analysis; GSE154200 treatment and pairing audit; independent GSE154200 benchmarking; and generation code for the manuscript figures and supplemental tables.

The code is a transparent comparator benchmark, not an exact reconstruction of the original published models.
